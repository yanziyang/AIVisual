About this visualization

Prompt

Visualize in 3D how DNA unzips and gets copied before a cell divides, hosted in standalone HTML web page.

Implementation details

This self-contained page uses JavaScript to project a 3D DNA model onto Canvas 2D. Drag to rotate, scroll to zoom, or scrub the replication timeline. The CPU calculates the 3D scene; no WebGL GPU renderer is used.

Source

AskPerplexity post on X

Simplified model of semiconservative DNA replication. Enzymes and the leading/lagging strand details are omitted to focus on the copying mechanism.
