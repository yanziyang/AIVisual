Original request

create 3D interactive view for UOB Innovation Hub, formerly The Hive, also known as Learning Hub South, is a building located in Nanyang Technological University (NTU), Singapore.

Build the 3D model using Blender, Hosted the 3D interactive view in standalone html.

The editable Blender scene, exported GLB, modeling script and viewer source are included in the project. The HTML embeds the GLB and viewing library.

How it was built

  1. Architectural references. Published Heatherwick Studio photographs and the Level 4 plan guided the irregular arrangement of twelve rounded towers, the open central atrium, stepped heights and garden terraces.
  2. Modeling in Blender. A reproducible Python script creates mesh geometry with Blender’s bpy API. Lofted oval profiles form the tapered classroom enclosures; horizontal ribs are modeled in the mesh. Recessed glazing, columns, bronze rails, four circulation cores and planting complete the study.
  3. Browser-ready export. Objects are joined by collection and material to reduce rendering work. Each tower keeps its own identifier. Blender exports a binary glTF model with material properties and metadata; the exporter converts Blender’s Z-up coordinates to glTF’s Y-up convention.
  4. A single HTML viewer. Three.js loads the embedded GLB directly from Base64 bytes. The renderer, loader, orbit controls, styles and model are bundled into one file, with no external runtime requests or CDN dependencies.
  5. Interaction and rendering. Perspective orbit, zoom and pan support mouse, touch and keyboard input. Preset cameras, tower picking, two clipping planes, daylight/evening lighting, shadows, auto orbit and fullscreen support exploration. The scene redraws when a view or control changes.

Rebuild the viewer

blender --background --python build/build_model.py
npm --prefix build install
npm --prefix build run build
npm --prefix build run preview

All build scripts and viewer source are in build/. Open uob-innovation-hub.html at the workspace root, or use the local preview. Hosting uses a synchronized copy at dist/index.html. The build bundles the exported model; it does not generate the building geometry in the browser.

Learning Hub South · Singapore

A different kind of learning space.

Designed by Heatherwick Studio with CPG Consultants and completed in 2015, the building brings twelve rounded towers together around a naturally ventilated central atrium. Garden terraces and shared galleries encourage people to meet between classes.

The building was known as The Hive before becoming UOB Innovation Hub in 2026.

This model is an interpretive architectural study built in Blender from published photographs and plans. The massing, ribbed façades, open atrium and planted terraces are represented; dimensions, room counts, floor arrangements and landscaping are approximate. It is not an as-built survey.
