# Stillwater pond

Open [fish-pond.html](fish-pond.html) directly in a WebGL2-capable browser. All runtime assets are embedded; no server or internet connection is needed.

Select Ripple or Feed koi and tap the water. Drag to orbit; scroll or pinch to zoom. Click the current light at the top right to choose Morning, Afternoon, or Golden hour; the selected preset updates the button and scene, including while paused. About this pond contains the prompt and implementation details.

Source files, engine assets, screenshots, build scripts, and checks are in [build/](build/README.md).
