ORIGINAL PROMPT

Create an interactive 3D submarine viewer in a standalone web page using the reference image 'US-Navy-Modified-Virginia-Class-Submarine-SSW-1536x864.jpg'.

First inspect the image, then build a recognizable 3D approximation of the submarine using Three.js. A single image cannot establish exact geometry or hidden surfaces, so infer those areas conservatively and prioritize matching the visible silhouette, proportions, hull shape, sail, fins, and other identifiable features.

Requirements:
- Construct actual 3D geometry, not a flat image on a plane.
- Use smooth curved surfaces and a realistic dark hull material. Reproduce visible details where the image provides enough evidence.
- Make the submarine the main focus in a full-window scene with neutral lighting and a subtle background.
- Include orbit, zoom, and pan controls, plus icon buttons with tooltips for resetting the view, switching wireframe mode, and downloading the model as GLB.
- Frame the entire submarine correctly on initial load and after resizing.
- Support desktop and mobile screens.
- Keep all application code in one HTML file. CDN imports are acceptable; clearly state that they require internet access.
- Ensure the page runs when opened directly from disk. If browser restrictions prevent that, provide a working local-server option.
- Verify the viewer with browser screenshots and canvas checks, including rotation, zoom, mobile layout, and GLB export.
- Save the finished HTML in the workspace and provide a clickable link to it.

Implement and test the viewer now. Briefly explain which features were inferred from the reference image.
