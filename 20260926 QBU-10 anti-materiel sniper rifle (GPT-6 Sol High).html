Original build prompt 
Act as an expert frontend developer and 3D web graphics engineer. Create a single-file HTML/JS interactive 3D web application demonstrating the mechanical decomposition (exploded view) of the QBU-10 anti-materiel sniper rifle.

Use a clean, modern, tactical dark-mode dashboard UI (Tailwind CSS) with a large 3D viewport canvas powered by Three.js (loaded via CDN).

Key Requirements:
1. 3D Model Presentation:
- Since a real QBU-10 GLTF/OBJ model isn't hosted on a public CDN, programmatically generate a highly detailed, accurate geometric approximation of the QBU-10 using Three.js primitives (Group, BoxGeometry, CylinderGeometry, TubeGeometry).
- The rifle must be clearly recognizable as a QBU-10, featuring distinct grouped components: Muzzle Brake, Fluted Barrel, Handguard/Receiver, Bolt Carrier Group, Optical Sight (YMA95/YMA06 style), Pistol Grip, Buttstock, Detachable Box Magazine, and foldable Bipod.
- Apply realistic tactical textures/materials: matte black/dark grey metallic finishes for the body, distinct steel sheen for the bolt, and a coated glass material for the scope lenses.

2. Interactive Decomposition (Exploded View):
- Implement an interactive "Decompose / Assemble" slider or toggle button.
- When "Decompose" is triggered, smoothly animate (LERP or TWEEN) the rifle components away from the center axis into an organized exploded view.
- Component separation paths: Magazine moves downward; Scope moves upward; Bolt Carrier slides backward; Muzzle brake moves forward; Bipod folds down/extends.
- Clicking an individual component highlights it (emissive glow) and isolates it in focus.

3. Tactical UI Dashboard Overlay:
- Title Panel: "QBU-10 12.7mm Anti-Materiel Rifle - Interactive Technical Schema".
- Information Panel: A dynamic sidebar that updates based on the selected/clicked component. Show the component name, primary function, and technical specs (e.g., "Magazine: 5-round capacity, 12.7×108mm DBJ-10 rounds").
