VELARIS Aurion GT · Configurator — README

Run

cd velaris\configurator
start.bat            (or: python -m http.server 8123)
→ http://127.0.0.1:8123/index.html

A local static server is required only because browsers block ES‑module and GLB loading over file://. There is no backend.

One Shot VELARIS Configurator Prompt

How to use it. Open a coding agent in a new project folder, attach the VELARIS reference images if available, and copy and paste the complete prompt below. Exact output can vary by model and available 3D tools, but this prompt defines the visual direction, interactions, file structure, and quality checks needed for a close result.

Create a complete standalone 3D car configurator for a fictional premium electric grand touring supercar brand named VELARIS.

Main objective

Build only the VELARIS configurator experience. Do not include unrelated landing-page sections. The result must feel like a finished luxury automotive product experience, not a generic dashboard, template, or simple Three.js demo.

Visual direction

- Use a cinematic near-black studio environment with a seamless dark floor and subtle atmospheric depth.
- Place the car prominently in the center on a wide, low, circular presentation podium with refined edge lighting and soft floor reflections.
- Use elegant, restrained typography and a premium glass interface with transparent charcoal panels, subtle blur, thin borders, soft highlights, and excellent contrast.
- Keep the composition spacious and dramatic. The vehicle must remain the visual centerpiece.
- Avoid purple gradients, colorful SaaS styling, cartoon effects, clutter, excessive glow, and fake decorative controls.

VELARIS vehicle design

- Create an original vehicle that does not copy or display the logo of an existing manufacturer.
- Use a low, wide, aerodynamic grand touring silhouette with realistic automotive proportions.
- Give it a long sculpted hood, smoothly curved front profile, muscular rear haunches, clean side surfacing, a low greenhouse, and believable panel separation.
- Use premium metallic liquid-silver paint with controlled blue-gray reflections.
- Add narrow high-definition LED headlights with realistic lenses, strong illumination, and believable reflected light on nearby bodywork.
- Build detailed performance wheels with deep forged rims, refined spokes, hubs, brake discs, calipers, realistic tire thickness, tread, and sidewalls.
- Use physically believable glass, rubber, metal, paint, leather, suede, carbon fiber, and display materials.
- The exterior must look polished from front, side, rear, and three-quarter views.

Configurator layout

- Fill the browser viewport and work on desktop, tablet, and mobile.
- Keep a large central 3D viewing area with the car fully visible and correctly framed.
- Add a refined glass configurator panel without covering important parts of the vehicle.
- Include clear tabs or modes for Exterior, Interior, and Equipment.
- Include paint selection, wheel selection, interior trim selection, and a configuration summary.
- Include useful vehicle specifications such as electric range, acceleration, power, and selected equipment.
- Add camera presets for front, side, rear, and three-quarter views.
- Allow smooth drag or orbit controls while preventing the camera from moving under the floor, through the car, or too far away.

Exterior interactions

- Let the user hover or click the driver and passenger doors to open and close them with believable hinge motion.
- The open doors must reveal a complete cabin opening with finished inner door panels, door jambs, seals, sills, seats, dashboard continuation, center console, footwells, pedals, and realistic depth. Never reveal an empty shell.
- Add a rear trunk or hatch control that opens and closes. Show a finished cargo area with lining, floor, trim, seals, and believable volume.
- Add a front trunk control that opens and closes with a believable storage compartment.
- Add a headlight control. When activated, smoothly move the camera toward a centered front view, illuminate both headlights, and show realistic light spill and reflections.
- Add a battery or charging control. Reveal an elegant charging-port or battery visualization with an animated energy path, controlled glow, and a running charge or range value.

Interior experience

- Add a button to enter a true immersive interior mode and another to return outside.
- Create a premium driver-focused grand touring cockpit with realistic proportions.
- Include a refined steering wheel, instrument cluster, infotainment display, dashboard architecture, vents, center console, believable controls, sport seats, stitching, seams, door trim, brushed metal accents, subtle carbon-fiber or technical trim, and rich material separation.
- Let the user look around with a constrained 360-degree interior camera without clipping through the cabin.
- Add subtle screen animation and an optional radio or ambient-audio control. Audio must start only after user interaction and must include an obvious mute or stop control.

Motion and presentation

- Create a polished opening sequence: fade the car in, move the camera slowly from rear or side toward the hero angle, reveal the VELARIS title and controls in sequence, and bring up the podium lighting smoothly.
- Use cinematic easing, staggered reveals, smooth camera transitions, and refined panel motion.
- Keep all animation purposeful and restrained. Respect reduced-motion preferences.
- Preserve responsive performance and avoid unnecessary heavy effects.

Technical requirements

- Use genuine interactive 3D geometry with Three.js or an equivalent browser-based 3D workflow.
- If reference images are attached, treat them as the master design reference and keep the same car identity across every view.
- If a suitable GLB or glTF model is included, use and refine it. If no suitable model exists, create the best original procedural model possible and clearly state visual limitations.
- Use physically based materials, realistic studio lighting, soft shadows, environment reflections, and sensible tone mapping.
- Keep materials and moving parts organized so paint, wheels, glass, lights, doors, trunk, front trunk, and interior can be controlled independently.
- Create a clean standalone index.html.
- Store all required files under assets, including assets/images and assets/models, and use relative paths that work after the project is moved or downloaded.
- Remove dependencies on unrelated website sections and avoid requiring a backend or paid service to run the finished configurator.
- Do not leave placeholder buttons, broken controls, missing files, external hotlinks, watermarks, or copyrighted manufacturer branding.

Quality and verification

- Inspect the actual rendered result from every important camera angle.
- Test paint, wheels, view presets, orbit controls, both doors, rear trunk, front trunk, headlights, battery or charging mode, interior entry and exit, interior look controls, radio or audio, loading animation, and responsive layout.
- Check for clipping, floating parts, hollow openings, incorrect pivots, misaligned windows, off-center framing, broken reflections, unreadable glass panels, and console errors.
- Refine visible weak areas before finishing.
- Preserve honesty: do not claim photorealism or production-quality geometry if limitations remain.

Final deliverable

Return a polished, self-contained VELARIS configurator with index.html and all required local assets. Clearly report what was created, what interactions were verified, how to run it locally, and any remaining limitations
