The starting point

The prompt

Help me create a video using JavaScript on the topic “What Is a Transformer?” Explain it clearly and accessibly, while still going into depth so that even high school students can understand it. Don’t just give a high-level overview—include the details, such as how the attention mechanism works, and even some of the math. You can use any tools or install whatever you need, and you can search the web. Surprise me!

How the video was built

The project uses JavaScript to draw original Canvas diagrams, generate a timed sequence of frames, and send those frames to FFmpeg. Narration is synthesized locally with Windows speech. The result is an MP4 with audio, visible captions, an embedded subtitle track, and chapter metadata.

VISUALS / JAVASCRIPT

Deterministic Canvas animation

@napi-rs/canvas creates the 1280 × 720 drawing surface in Node.js. The drawing function takes the scene, timestamp, and caption. Fades, traveling signals, network movement, and growing bars are calculated from time, making frames reproducible.

The design uses a dark grid, mint signals, coral and lavender accents, and large diagrams with a dedicated caption area.

AUDIO / LOCAL SPEECH

Narration sets the timeline

prepare.js calls Windows System.Speech with the installed Microsoft Zira Desktop voice. Each narration segment becomes a WAV file. Reading its audio duration determines the scene boundaries and keeps the visual sequence aligned with the speech.

No remote speech service or API key is required. The speech preparation step requires Windows and the installed voice.

ENCODING / FFMPEG

Frames become a playable video

render.js streams raw RGBA frames to ffmpeg-static. FFmpeg encodes H.264 video and AAC audio, adds a mov_text subtitle track and chapters, and uses fast-start metadata for browser playback.

Encoding settings: 24 fps, YUV 4:2:0, CRF 20, and the veryfast H.264 preset.

LEARNING / COMPANION PLAYER

Pause, jump, and experiment

The companion page includes the original prompt, 26 chapter buttons, download links, and a query-changing attention playground. The playground recalculates scaled scores, softmax weights, and a blended output vector immediately.

Visible captions follow individually timed narration segments. The separate subtitle files estimate sentence boundaries within those segments.

The production pipeline

Write a structured lesson

scenes.json holds each scene’s title, diagram type, and narration. The lesson starts with context and tokens, walks through attention arithmetic, then covers multiple heads, feed forward networks, residual connections, normalization, masking, training, and generation.

Prepare speech and timing

prepare.js generates narration clips, measures their durations, and writes timeline.json, SRT and WebVTT captions, and the transcript.

Draw every frame

visuals.js draws the diagram for the active scene. At each frame, render.js looks up the active narration segment and renders the matching caption and progress indicator.

Encode and review

FFmpeg combines picture, narration, subtitles, and chapters. The finished video is checked for readable layouts, numerical accuracy, correct media streams, browser playback, and seeking.

The attention math, made concrete

The lesson uses synthetic two-dimensional vectors so students can calculate the mechanism by hand. These numbers are illustrative, not measurements from a trained model. Keys and values happen to match in this example; in real attention they generally differ.

Attention(Q, K, V) = softmax(QKᵀ / √d_k)V

Q contains queries, K contains keys, and V contains values. Transposing K makes matrix multiplication compare each query with each key. Divide scores by √d_k, apply softmax independently across each row, then multiply by V to blend the values.

CandidateKey / valueDot product with q = [1, 0]Scaled scoreAttention weight
A[2, 0]21.41457.6%
B[0, 2]00.00014.0%
C[1, 1]10.70728.4%
softmax(s)_j = exp(s_j) / sum(exp(s))

output ≈ 0.576 × [2, 0]
       + 0.140 × [0, 2]
       + 0.284 × [1, 1]
       ≈ [1.436, 0.564]

Here d_k = 2. The exponential function exp(s) is e raised to s, where e ≈ 2.718. Softmax gives positive weights that sum to one. The final attention output is a vector, not a selected word.

Try the implementation

Change the query, change the recipe

Try [0, 1]: B receives the largest weight. Try [0, 0]: the weights are equal.

const scores = keys.map(k =>
  (q[0] * k[0] + q[1] * k[1]) / Math.sqrt(2));
const max = Math.max(...scores);
const exponentials = scores.map(s => Math.exp(s - max));
const total = exponentials.reduce((a, b) => a + b, 0);
const weights = exponentials.map(e => e / total);
const output = [0, 1].map(d =>
  values.reduce((sum, v, i) => sum + weights[i] * v[d], 0));

Subtracting the maximum score preserves the softmax result while reducing the risk of numerical overflow.

File layout and reproduction

The final video, this combined video and documentation page, and README.md are in the workspace root. Supporting files are kept in the transformer-video subfolder.

To reproduce the video, run these commands from the supporting-files folder. Node.js, Windows System.Speech, and Microsoft Zira Desktop are required. The renderer writes the finished MP4 into the parent folder.

npm install --no-audit --no-fund
# If npm blocks the FFmpeg download script:
node node_modules/ffmpeg-static/install.js

node prepare.js
node render.js
node verify.js

# Optional local companion player:
node serve.js

What was checked

The attention example produces [1.436, 0.564]; swapping the query produces [0.564, 1.436]. All 26 scene layouts were rendered and reviewed. The narration check found no clipping. The final MP4 contains H.264 picture, AAC audio, and an embedded subtitle track.

Browser behavior

The companion player loaded the 1280 × 720 video with a duration of approximately 665.5 seconds. Seeking and playback worked, all 26 chapter buttons were present, and the mobile page had no horizontal overflow. Verification results are saved with the supporting files.
